# Security

Report a vulnerability privately through GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/geovannyAvelar/mapnik-java/security), not in a public issue.

The native bundle contains Mapnik and its dependencies (PROJ, ICU, FreeType, HarfBuzz, libpng and others).
Their versions are in `NOTICE` inside the natives jar. A vulnerability in one of them is fixed by a new
natives release with the library updated.
